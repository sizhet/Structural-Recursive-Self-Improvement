# 5. Fig-004 — Two-Way CCC and Counter-Evidence RSI

**File:**

```text
figures/Fig-004-Two-Way-CCC-and-Counter-Evidence-RSI.png
```

## Role

Canonical mechanism figure for Anti-Goodhart SRSI.

## Core Meaning

The figure combines two core mechanisms:

```text
Current Structure A
        ↕
Two-Way CCC
        ↕
Candidate Structure B
```

with:

```text
Evidence
   ↕
Counter-Evidence
```

The resulting improvement decision is not limited to:

```text
B wins
```

but may become:

```text
PROMOTE

REJECT

BRANCH

LOCALIZE

LEFTOVER
```

This figure visually expresses the key Anti-Goodhart principle:

> **Do not ask only whether the candidate wins. Preserve enough structure to understand where it wins, where it loses, and why.**

# 13. Figure Design Philosophy

The SRSI figure set follows several principles.

## 13.1 Concept Before Decoration

Each figure should communicate one major structural idea.

## 13.2 Minimal Figure Count

Five figures are sufficient for the v1.0 framework.

The repository does not need one figure for every section.

## 13.3 Structural Consistency

Across the figures, recurring concepts should remain visually recognizable:

```text
Generation

Evaluation

Counter-Evidence

Localization

Governance

Memory
```

## 13.4 Repository-First Usage

Figures should remain understandable when viewed directly inside GitHub.

## 13.5 Presentation Reuse

The same figure set should be suitable for:

* GitHub,
* ResearchGate,
* DOI overview PDFs,
* slides,
* posters.
